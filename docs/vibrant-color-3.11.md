# adu-motion-video 3.11.0 · 活力色彩与提炼 Skill

2026-10-04。新增 06-A「活力色彩」`vibrant-color-performance@0.1.0-candidate`，1080×1920/60fps，仅原生竖屏。当前竖屏目录 11 风格 / 39 组；横屏仍为既有 10 风格 / 32 组。既有冻结包与已交付影片不改写。

## 本轮改动

四组完整原编舞：答案划除→问题、四步骤→归一、回声聚焦、三项成本→结论。保留真实 source clocks、helpers、Canvas、人物卡、前态、竖向/横向擦除与动作声音。另增三组同风格基础动画：关键词与解释、双要点、结论与展开说明；这三组标记 `newly-authored-style-extension`，不是声称来自原片的新提炼。

公共配置品牌、账号、网址为空，人物标签使用本期输入。清理 helpers/HUD/默认标签中的本期身份和原片标题；公共包无人物、头像、成品墙、旧字幕、商业录音或个人路径。追溯使用匿名修订和代码摘要。

三组基础动画支持换行及中间阅读区延长最多600帧；入场、退出和音效只执行一次。原四组没有合法延长区，短段、错误数量、超容量、超长单组和声音支持不足应拒绝。中文近上限测试发现回声标题宽度不足，关键词容量收紧到9字符，保持72px可读下限，没有用裁字或无限缩小掩盖问题。

新增可独立安装的 [adu-template-extractor Skill](../skills/adu-template-extractor/SKILL.md)，将来源冻结、去个人化、基础动画、语义槽、文本容量、原生画幅、媒体/HDR、输出时钟、声音尾音与发布证据纳入每次提炼。Windows/WSL、macOS、Linux；Codex、Claude Code、豆包、DeepSeek、WorkBuddy按实际文件/命令能力使用。本轮实测平台为macOS。

## 限制与使用

保持candidate。上述自动检查、源局部几何对照、合成构建和静音示意不代替真实新口播连续声画或独立使用验收，manifest对应门槛仍pending。原源登记整体仍received，7组关联不晋级全部25场来源。

原四步骤组表达自动化导致同质化，不是通用四条清单；三条成本柱和0–100仪表是固定演出示意，不可当真实报价/统计。新素材须使用共享色彩流程；本轮合成8bit轨道缺色彩标签，色彩receipt明确保留SDR默认假设，不作为HDR/DV真人素材验收。

三份外部字体需所有者供给；中文字体按当前系统许可与实际宽度核验。默认底乐是合成替代，非源商业录音；保留原视觉脉冲的同时，换曲必须复核节拍和连续听感。容量及真实输入见[模板说明](../references/vibrant-color-template.md)。
