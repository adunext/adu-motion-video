# 长短素材与重复演出压力测试 · 3.9.0

2026-10-03。本轮覆盖目录当前十种风格、32 个完整组，以及横屏和原生竖屏。测试采用自动生成的图像、运动测试视频、静音音轨及明确标注的测试 cue；原始工程、冻结包和已有成片均未改写。详细参数、包 manifest SHA 与逐案结果见[机器记录](template-stress-3.9.json)。

## 本轮修复

| 问题与复现 | 修复后的行为 |
| --- | --- |
| 长片中同组重复的累计惩罚超过缺绑定惩罚；350 段都有可用 A 组，B 缺标题，仍选入 12 段 B 而报告 needs-binding | 先按绑定完整程度排序，再优化变化；350 段都选已绑定组，并明确提示重复程度，不拿缺素材换效果 |
| brief 声明 1,200 秒口播，分镜只有 4 秒，规划仍显示 ready | 在规划和构建复核时按帧网格阻止总时长不一致；改 ready 标记不能跳过 |
| 实际口播长度不匹配，旧流程直到大量抽帧后才拒绝 | 使用与导入器相同的视频时钟计算，先读真实音视频元数据；不一致就停止，匹配后仍复核实际导入帧数 |
| 音效跨入延长的阅读区，生成器 `d=0.5` 被映射为 `2.9` 秒 | 只映射起音点，保留原生成器秒数；以使用 d 参数的 typing 音效回归，既有前置起音仍保留 |
| `minFollowingFrames` 只在最终编译检查 | 规划候选与手改 spec 复核使用同一尾音支持检查；不同输出帧率向上取整，不截断声音 |
| 没有直接展示全片重复程度 | Markdown 和机器报告新增 `rhythm`：使用次数、总时长、连续重复、两三组固定循环、同类动作连续使用，以及新增超过四秒的停留 |

重复提示是复核信号。只有一个语义成立的组时，工具保留它并指出覆盖不足；新增候选、调整表达或设计新变体须有内容依据。不会随机换动画、补造事实或删除音效以获得表面变化。

## 浏览器与声音时钟

实际 Chrome 执行当前冻结场景代码和新共享 runtime。每个组实例化三次，第二轮在有合法停留区时延长到 hold 上限；没有可停留区的 s02/s03 明确使用原时长，未冒充已经支持延长。两种画幅共 **192 个场景实例、1,980 次寻帧**，覆盖运动窗起止、晚帧、逆向与再次进入。

- DOM 与可见 Canvas 在正向、逆向及重复寻帧中一致；隐藏元素的懒更新不作为画面差异。
- 运动窗保持源 1×，没有用反复启动、整场慢放补足时长。
- 每个实例的音效事件只采集一次，事件数及生成器 d 保持；寻帧不再添加事件。
- 十个风格各自三轮时间轴合计 1,343.45 秒；它不是一条混剪视频。最长单路线为 03-A 的 346.2 秒，两种画幅均完成寻帧检查。

浏览器使用系统字体、短测试文案和示意图像；该范围不包括真实人物口型、事实适配、全部最长文字的读字体验或最终编码试听。另一条已有 03-A 的 329 帧真实构建回归也执行了媒体导入、寻帧检查、SFX 采集和冻结声音脚本；其单独片尾场作为开场的已知人物警告仍保留。
