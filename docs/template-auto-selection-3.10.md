# 3.10.0 全库选型与长短素材测试

日期：2026-10-04。新代码用于以后生成的工程，既有视频和冻结模板包保持原字节。完整混合路线为 experimental，模板发布等级不因机器测试改变。

## 本轮完善

- 加入全库能力导出、完整单风格与合法跨风格路线比较、不同完整分段路线比较、可编辑工程构建。
- 先满足内容与绑定，再考虑风格一致和变化；可为不同模板保存各自的表达、短句和真实动作落点，构建会重新验证。
- 缺字体、错误字体身份、短视频区间、文字溢出、过短或超长单镜头不能报告为可用；自有音乐从指定偏移起须覆盖全片，不能自动循环。
- 长段可选助手依据真实台词提出的其他分段路线，总帧数不变；不切开原子动作、不随机添加表达阶段。
- 混合工程只导入一次母版，子工程沿整数帧和 PCM 样本取区间；根工程使用完整母版声音。字幕按全局时间显示；动作音效的前奏、起音、生成器时长和跨包尾音保持。
- 测试发现纸面天平的局部图片更新没有进入原 imgWait。补齐子工程可见图片的解码与字体等待，避免接缝时偶尔读取尚未完成的新帧。
- 修复源纸面天平隐藏元素反复追加零缩放的历史累积；共享运行层合并等价重复，非零变换保持。跨模板导出统一使用软件绘制，避免 GPU 合成的少量像素差异。
- 源配乐按包保留自己的配方，跨风格切镜处采用 120ms 音量坡道；这是新的组合策略，需要连续试听。

## 仍需实际制作判断

执行助手必须核对语义标注忠于台词，不能用伪造阶段或数量让模板通过。字体渲染、真实人物裁切、复杂证据的可读性、风格切镜和音乐衔接仍需连续观看与试听。32 组均参与选型，不等于任意两组都能自由连接；依赖原有物件续接的入口不跨风格自动使用。

接口与流程见 [全库选型](../references/automatic-selection.md)。此前 567 个长短素材案例的定义和结果见 [3.9 压力记录](template-stress-3.9.md)，本轮回归继续包含该压力测试。
