# adu-motion-video 3.14.0-rc.1 · 兼容性升级

2026-10-05。本版为本地兼容性候选；此前公开版本为 3.13.0-rc.2。没有替换其他安装副本、ADuDir 桌面内嵌 Skill 或历史冻结工程。

## 用户可见变化

- Windows 原生 PowerShell/CMD 和 macOS 共用 Python 制作入口，不要求 Windows 用户安装 Bash。已有 Bash/WSL 入口继续可用。
- 原字体、字重与 SF Mono 仅优先推荐。缺少原字体或推荐文件不可用时，自动使用随包 Noto Sans SC / Noto Sans Mono；工程保存实际字体、替换记录和许可证，离线渲染无需另装字体。
- 用户自己的有效字体可作为替代，不要求与原字体指纹相同。只有用户明确要求精确源字体复刻时才启用 exact。
- 自动人物检测优先采用可用的本地工具：macOS Vision、其他环境 OpenCV。检测不可用时保留宽幅固定构图，提示实际裁切复核。
- 处理中文、空格和特殊字符路径，识别两种系统的虚拟环境目录，补充 Edge 查找；依赖按当前 Python/系统选择可用版本。
- 同一份 Skill 面向 Codex、Claude Code、豆包、DeepSeek、WorkBuddy 等具有本地文件和命令执行能力的助手。仅聊天客户端仍需要执行环境。

字体回退不是原字体视觉复刻保证，须检查实际断行、标题、字幕及少见字形。真实媒体、数量、时长、画幅和动作窗口依然需要匹配。HDR 转换、音乐绑定、动作音效及旧工程声音配方不因跨平台升级而放宽。

## 使用入口

在实际 Skill 文件夹运行，所有素材路径加引号：

| 操作 | Windows | macOS/Linux |
| --- | --- | --- |
| 检查环境 | `python scripts/pipeline.py doctor` | `python3 scripts/pipeline.py doctor` |
| 安装本 Skill 依赖 | `python scripts/pipeline.py setup` | `python3 scripts/pipeline.py setup` |
| 查看模板 | `python scripts/pipeline.py packs` | `python3 scripts/pipeline.py packs` |

其余命令及字体策略见[平台与助手兼容说明](../references/compatibility.md)。setup 不安装系统 Python、Node、FFmpeg 或浏览器；这些是实际制作工具。字体是随包资源，不是需要用户补交的素材。

## 分发与保留

随包字体是原样的 Noto 字体，包含各自 OFL 许可证、固定来源提交和文件摘要。原模板包、动作编舞与音乐/音效时间轴保持原版本。新工程保存字体选择及本地资源，旧工程不隐式迁移；提炼方法 Skill 仍只在本地，不进入公开仓库或安装包。
