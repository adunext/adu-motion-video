# 3.6.0 模板适配与素材处理

这次完善覆盖现有语义计划的局部重配、输入消费检查、通用视频槽的色彩链路，以及 04-A 新候选的文字容量。稳定包等级未改变，旧冻结包与已有成片保持原字节。

## 局部重配

`macro-rematch` 检查同组换素材或调用方明确设计的其它候选组；`macro-apply-rematch` 基于原配置、合同和素材摘要重新计算后保存新计划。仅指定段落可改变，段落语义、时长、真实 cue、其它分镜与全片声音设置保持原样。新目录所需的绝对路径另列迁移 diff，原文件完整字节随建议保存。

验证包括锁定段落、两侧接缝、前后依赖、缺少关键词时码、标题容量、图片/视频类型与比例、真实视频可播放长度、文件同名覆盖、目录帧库存变化、请求/候选篡改，以及保存后原工程不变。报告列出每个素材的消费槽位，未被替代组接收的新绑定不会获得 ready。

独立复核另复现并修复两个边界：同槽的候选输入与新增绑定互相冲突时明确拒绝，不能静默选其中一个；已导入工程的 `voice.wav` / `import.json` 也进入摘要，即使配置未改、文件被新增/删除/替换，旧建议仍需刷新。

同意图缺少不同动作的已提炼变体时，保留原组是合法结果。这里的确定性匹配接口尚未接到 ADuDir 拖放 UI，不能用本次模板库验证冒充桌面端体验验收。

## 输入与色彩

语义展开拒绝未被槽位使用的字段和数组项，不能靠自报 `counts` 掩盖多出来的实际输入。此检查揭露公开示例中第二、第三支点的无效 `sample` 字段；示例已按真实 `label` / `record` 槽修正，叙述关系不变。旧冻结包里的有效示例保持原样。

通用 video 抽帧复用共享 `image_plan`。`media_color.json` 独立记录逐素材来源 SHA、颜色转换和 JPEG SHA；导出与交付验证核对这些帧，缺少记录或已被替换时拒绝通过。色彩风险记录逐素材匹配，口播记录不能代替其它视频。探测缓存按文件修订刷新，比例按旋转与 SAR 的显示尺寸检查。

实测包含 FFmpeg 生成的 SDR/HDR 视频、90° 旋转、非方形像素、同路径覆盖并恢复 mtime、实际色彩像素转换、浏览器六帧导出及 receipt/图像篡改反例。正常 10 位 HDR 转换通过不等于已人工确认肤色；预处理静态图与旧序列的上游转换仍需单独追溯。
