# 活力色彩原生竖屏接入

`python3 adapters/vibrant-color/extract.py SOURCE_RECORD adapters/vibrant-color/proposal.json NEW_PACK`

只接入proposal固定的完成修订；SOURCE_RECORD由source_registry登记在私人输出目录。核验源文件、AST语句和adapter端口，保留四个完整组及helpers，隔离私有DOM/Canvas，不实例化原25场中其它21场。另从 basic-scenes.js 接入三组新编基础动画，单独固定文件和语句SHA并标记为新创扩展，不能声称属于源25场。

保留源码动作与原生1080×1920层级。移植端口为媒体/人脸输出时钟、HUD新进度、品牌、源宿主、音效一次转发、输出字幕与原方向转场；源码helper仍是原几何。独立前态取自真实上一tkKey，并在组初建立，不猜新邻居姿态。字体仅索取三份实际消费的Anton/Geist Mono，不捆绑二进制；中文字体按当前环境检查。

源audio.py的CUTS/CLIMAX/DIP/HITS以AST静态读取，源音量函数以已审查计算冻结；不执行源脚本，不复制私人音乐路径/录音/循环补长策略。重合成底乐明确作为替代。源20个SFX通过共享运行时保留生成器长度，minFollowingFrames按完整生成器加0.9秒混响支持计算。

四组完整保护，无hold扩展；只有portrait合同。实际源码、换稿、浏览器、构建和声音证据分别写入docs记录，保持candidate，不宣称整片或独立真人验收。

三个新基础组共有7个独立SFX，原四组20个；静态阅读区可延长最多600帧，入场、退出与尾音不变。公共身份字段为空并扫描个人信息；来源追溯只保留匿名修订和代码摘要。
