# 一份 inline DOM 来源的专用接入

此 adapter 仅处理已复核的国庆 v1 来源修订。它是不同运行契约的适配实例，不把任意 HTML 当作可自动拆分的 Scene 工程。其它契约先保存来源，确认演出价值后各自适配；已经使用 Scene 的工程仍走通用 `extract_authored_pack.py`。

```bash
python3 adapters/paper-balance/extract.py "$PRIVATE_SOURCE_RECORD" "$NEW_PACK_DIRECTORY" --version 0.1.6-candidate
```

源记录先由 source_registry 完整验证；入口、来源修订与五个字体文件再按已审查哈希验证。任一内容不同都拒绝，不执行源代码、不改原工程。提取范围与有意适配写入 manifest。输出必须不存在且父目录存在。

天平/用途/批注与后三步小球是一个完整组，不能只提取倾斜效果。全局人物姿态与 3D 运动函数保留，局部父图层接到现有 Scene 宿主；人物帧和裁切使用本期输出钟。保留前组在边界处的闪光释放，前后组的未选内容不实例化。只共用宿主所需的布局样式，不让 A 的字体平滑、通用类和人物标签滤镜改变此来源的演出。字幕沿用现有输出钟合同，私人音乐不随包分发。

有意适配：原片在深色章节隐藏字幕；新内容字幕保持在后三步下方，承载本期口播。私人同内容复核使用原字幕逻辑与原人物像素，单独核对原演出，不将它计为新内容验证。

字体内版权/许可核对后，将未改动的 WOFF2 与完整 OFL 通知一同嵌入 CSS，使生成工程保留通知。原中文系统字体另列为环境依赖。改变来源、运行代码或参数容量时使用新包版本；旧工程已经冻结的运行文件不会被改写。

提取后先完成原演出区间对照、新内容短段与输入边界检查，再用 source_registry link 关联清单；关联不晋级质量。追加包即可进入动态目录，当前过程不改主 Skill、构建器或 A/B 配方代码。仅一个组的验证不代表整个源工程或新路线已经稳定。
