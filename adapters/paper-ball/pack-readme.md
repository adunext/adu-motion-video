# paper-ball-performance@{PACK_VERSION}

候选：纸面、小球、手写与内容交付。只包含 `cards-to-network` 和 `calendar-to-delivery` 两组，原版 35 场的其它演出不在此包内。保持来源的物理、全片元素编号种子、人物走位、逐字落体与动作音效；通过专用适配器接入现有 `authored-unit/1` 宿主。许可与声画验收分别记录，候选不代表稳定发布。

`cards-to-network` 保留六张资料卡的出现、旋吸、小球增长、放射网络与结论句点；适合讲输入聚合形成方法，不能把符号图称为实际数据流。结论最多六字，卡片标签最多五字。六卡与十一节点固定。

`calendar-to-delivery` 保留七张日历页、六个能力标签、三件开箱产物与十张示意交付卡；两段源回调作为一个组接续。月份、计划名、时间背景、主题、能力、产物、结论、交付标题、编号和示意说明都须绑定本期内容。页数与卡片数固定，不能据此宣称实际交付数量。

人物与字幕使用输出时钟；内层编舞使用源时钟。源人物卡的入场沿用前章位姿，单独开场可能有移动过程，连接须看实际连续视频。保护窗口内不慢放动作，最多增加三秒可停留阅读时间；过短、缺字段、缺 cue 或超容量会拒绝。

显式提供本期口播、双语字幕与自有身份。没有必需作品墙、生成插图或录屏输入。字体 `YSBT` 是原优设标题黑；官方说明免费商用，但本包不附其二进制。配置 `externalFontFiles:{"title":"/本机/YSBT.ttf"}`，只接受已审查 SHA256 的源字节，复制到用户生成工程并记录，不自动换字体。取得和再分发字体的权利由使用者确认。其余五个源 WOFF2 随完整 OFL 声明嵌入；PingFang SC、Hannotate SC 依赖 macOS。

动作 SFX 随新时序重映。默认 synth 为明确声明的新配乐，不能称为原曲重现；需要原曲风格时显式指定有权使用的完整音乐轨道。原来源成片刻意无人声，仅用作私人同内容对照；新内容可保留新口播原声。

当前验收：同内容连续声画、新内容、冷安装与独立使用均待记录。仅支持待核验的 macOS 1920×1080、60fps；不承诺 Windows、竖屏或阿杜导演直接导入。
