# 模板视频预览

首页预览图与“播放示例视频”指向本页，使用仓库已公开的 GIF/MP4。提供原生视频控制、进度拖动、全屏和示例下载；没有外部播放器或统计脚本。

线上：https://adunext.github.io/adu-motion-video/examples/gallery/?template=01-A

桌面每行最多三项，移动端降为两列或一列。template 为风格编号；03-A 可加 layout=portrait 查看已有竖屏示例。模板支持画幅与实际示例影片分别标明。

GitHub Pages 从 main 根目录发布，.nojekyll 保持静态文件原样。私人媒体与提炼 Skill 不参与展示。
