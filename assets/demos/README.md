# 首页 demo

[九风格竖屏构图示意](portrait-layouts.webp) 是 3.7.0 原生布局预览的静帧拼图：仅自制 SVG 占位素材与系统字体，不含真人或原配音。它不是九部新口播成片，也不改变下表原样片的验收范围。可交互的占位预览生成方式见[开发预览页](../../examples/portrait-catalog/README.md)。

这些是项目所有者授权用于 GitHub 介绍的观看样片；原始口播与工程不随预览分发。

MP4 使用 960×540、24fps 和 AAC 音轨；GIF 使用 400×225、8fps。仅用于轻量预览，正式制作规格仍按所选模板。GIF 是正常速度短段，不代替完整 demo。导出核验见 [media-validation.json](media-validation.json)。

C/D/E 的观看文件保持原导出字节。3.2.0 各发布三个已验证完整组；这些源风格短段不替代新内容整片证据，也不表示来源所有镜头都可复用。实际组范围见[能力矩阵](../../docs/capability-matrix.md)。

03-A 来自不同内容九场新片的 45.8–53.8 秒，展示所有者口播和本人旧仓库实录，移除声音。横屏为 960×540，竖屏为 540×960，均 24fps；GIF 为 400×225 / 225×400，8fps、64 帧、8 秒。完整两片各 108.4 秒，由冻结公开候选冷安装重建，技术检查完成、连续声画待作者确认。完整私人影片和原始口播、录屏不作为模板输入分发。规格与源摘要见 [03-A-validation.json](03-A-validation.json)，完整边界见[验证记录](../../docs/validation.md)。
