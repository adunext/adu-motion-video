# 全模板原生竖屏

3.13.0-rc.1 当前候选版本及新增组以[质量升级说明](quality-upgrade.md)和机器目录为准；本文原有版本表保留历史验收范围。新默认竖屏字幕底部留白18%，由所有者看样指定；原冻结工程位置不自动改写。

当前目录的 01-A～01-E、02-A～02-B、03-A、04-A、05-A 共十种风格、32 个完整镜头组均有 **1080×1920、60fps 候选版本**。完整版本映射见[模板目录](template-catalog.md)。旧稳定包和旧成片保留原字节；竖屏候选的技术检查不追认成新的稳定声画验收。历史 anim3/anim4 实验场景、基础 TPL 和手绘方法不在这 32 组范围内。

## 从选型到导出

用户要求竖屏时，读取 template-catalog.json 对应风格的 **portraitSelection**，显式选择该版本；在本期 adaptation brief 顶层设置 **layout: "portrait"**，与本期 segments、素材、文案、真实 cue 锚点一起提交给 macro-plan。它会写入生成的 spec，macro-build 冻结布局运行代码、目标尺寸和来源指纹。也可在手写 macro spec 顶层设置 layout。默认 landscape。

然后沿用[完整工程复用流程](full-project-templating.md)完成音频生成、混音和 render。导出器从工程计划读取画幅，不必再手填 W/H；显式指定与工程不符的尺寸会拒绝。旧包没有竖屏契约时须选目录中的新版本，不能只把编码尺寸改为 1080×1920。旧 03-A 的手动布局 sidecar 优先保留它已明确保存的尺寸。

## 提炼时就保存两种布局

一个镜头组保存同一套语义阶段、固定数量、cue、受保护动作窗、素材与音效时钟，再为横屏和竖屏分别声明布局。源码单位与声音配方在本次版本中与对应基线逐字节相同；布局运行层处理位置和大小，不另建声音或媒体时钟。

- 标题、人物、证据窗口、观察项和片尾各自重排。人物与图片等比缩放，沿用本期裁切和采样，不拉伸真人。
- 杂志分屏与节拍字效中的右栏观察项改为证据窗下方的信息行；纸面物件、路径、小球和墨迹保持同一坐标映射。
- 控制台的三步骤改为竖屏步骤行，代理与交付卡改变栏位后，连线、发光球和粒子按新坐标绘制，沿用源激活及冲击落点。不声称源横竖屏栅格相同。
- 字幕在原生竖屏根层排版，中文 46px、英文 30px，并保留换行与底部空间；本期最长双语字幕仍须检查。
- 大标题按可用宽度拟合；共享原生布局在有效标题字号低于 44px 时拒绝，提示缩短槽位或换完整组。嵌套卡片沿用各包自己的容量规则，不能把这个阈值说成所有小字的保证。

新来源通过 authored 提炼时，在 proposal 的 layouts 声明 landscape 与 portrait，列出 reviewed runtime / stylesheet 并加入 sourceFiles 指纹。提炼器会保留并冻结这些文件。源码变动须重新审查布局，不能只因 pack ID 相同复用旧映射。

## 本次检查与实际限制

3.7.0 对九种风格的 29 个完整组使用真实 macro runtime 做了 **565 次寻帧**，覆盖 cue 邻域、前后寻帧、可见 DOM 和 Canvas 状态、横竖屏 SFX 事件一致性。Canvas 像素回归固定软件栅格，排除浏览器读取像素后切换后端带来的差异；不是跨平台逐像素承诺。不可见节点允许保留源实现的懒更新状态，重新可见时另行核对。

01-A 使用无真人、无配音的技术素材完成实际构建、混音及 928 帧导出：1080×1920、60fps、15.4667 秒，13 个源动作音效事件，配乐采用原配方。导出帧钟、帧数、完整解码与音轨检查通过。此例证明构建链，不能当作真人裁切、不同文案连续运动或全片试听验收。

九风格可切换布局预览采用明确的占位素材和系统字体，不装入私人人物、录屏或配音。上线前仍按本期真实素材检查最长文字、最多物件、人物头部与嘴巴、明暗切换、重排接缝及最终编码声音。字体换了或文案变长，就要重新核对宽度。现有语义规划、固定数量、精确 cue 和多样性规则继续生效，画幅适配不会为不合适的文案补造证据。

## 旧工程的局部配方

examples/portrait-shell.html 仅是历史工程的分区配方，需引用工程内运行时、人物帧和字幕。只有横版信息缩小后仍可读时才适合把局部内容放入缩放容器；密集表格、九宫格、多栏长文应重排或拆页。它不是当前九风格原生候选的默认实现。部分旧 ?vert 参数会关闭字幕，使用前检查代码。

手绘续接仍按[手绘动画方法](handdrawn-animation.md)安排人物、道具与字幕；它目前是制作方法，不计作本次新增完整模板。

3.8.0 新增05-A的三个完整组，分别为光环关键词、贴纸交接与反馈升级。它们另做489次寻帧，覆盖横竖屏、正常/近上限中文/近上限英文，八份固定SHA字体及反向Canvas/DOM状态；27个源动作SFX保持。记录独立于上面的3.7.0九风格565次检查，不合并成真实声画验收。
