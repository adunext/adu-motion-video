# 更新已有的源码安装

新版 `.motion` 包使用 MotionGit 官网和包内升级入口。本页只用于仍在使用本仓库源码工具的旧安装。

1. 从本仓库的官方提交或正式发布获取一个完整的新源码副本，核对来源，另存到新目录。不要覆盖旧安装，也不要把工程目录当作源码更新目标。`source-update.json` 的摘要用于检查下载内容是否一致；摘要本身不证明下载来源。
2. 从新副本运行以下命令；Windows 使用 `python`，macOS/Linux 使用 `python3`：

   ```text
   python scripts/pipeline.py update-source "旧安装的绝对路径"
   ```

   也可使用 `python scripts/update_source.py "旧安装的绝对路径"`。由助手执行并保留 JSON 结果，无须先准备本期素材、浏览器或编码器。
3. 每次源码更新都运行这个入口，包含官方运行模块曾被改动或清空的情况。入口先校验新副本的公开清单，再校验旧安装的受支持结构，恢复声明的运行模块和必要调用区域；重复执行应返回空 `updated`。未知结构会停止，写入失败会尝试恢复原文件并报告错误。
4. 核对结果的 `sha256`、`projectsWritten:false` 与 `configurationWritten:false`；保留旧工程、参数、音视频、Key、依赖及无关源码修改。更新仅涉及清单声明的两份文件，其他维护仍按原流程逐项处理，不能用 `git reset --hard` 代替此入口。

在旧安装中继续使用原有 `stills`、`render`、`preview` 流程。新源码副本与旧安装可能包含其他版本差异，本入口只提供上述兼容维护，不宣称同步全部文件或自动更新其他副本。Windows/Linux 的源码检查与单元回归不等于硬件视频验收。
