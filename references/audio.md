# 配乐 / 音量曲线 / 混音

## 本期配乐选择

3.12.0 新工程使用 `music:{mode:"track",path:"本期曲目路径",offset:0}`。曲目可来自用户授权文件或应用登记音乐库；助手按表达、节奏与许可选择，不把测试信号或某一首歌当所有风格默认。实际 path、offset 和文件 SHA 固定在工程，换文件需重新选择/规划。

- `offset` 必须明确且非负，偏移后须覆盖完整影片；不足则换曲或提供事先编辑好的完整音轨，不自动循环。
- 缺曲目/偏移时保存 needs-binding；构建和 audio 阶段都拒绝旧 `synth` / `source-synth`。旧默认生成器 `adu-source-score-synth-v1` 的所有时长变体已淘汰，已知旧 WAV 改名也拒绝。登记见 [音乐策略](music-library.json)。
- 用户明确不要背景音乐时才使用 `music:{mode:"none"}`，动作 SFX 仍保留；合成布局测试可以显式无 BGM。
- TPL 的 `audio.py` 中设置 `MUSIC`；`demo` 明确是无口播、无 BGM 的音效/布局示意。真实制作的 `new` 不自动选择无音乐。
- 起鼓点、ENV、DARK 和片尾淡出按本期素材检查。`offset = 起鼓秒数 − 第一个大切点秒数` 只可作非负且实际试听成立的起点；示例数值不能替代本次测量。

混合模板使用全片一首显式曲目，子工程不提供 BGM 回退，不因换风格重启或循环音乐；音效在全片时钟合成，跨场尾音保持。新运行时在动作 SFX 前单独重置种子11，曲目/音乐重音不会改变 SFX 噪声序列。此新随机合同不宣称与历史 synth 工程逐字节相同；已验收旧片换乐优先直接保留旧 voice/SFX stems，仅替换 BGM。

旧公开预览、源谱追溯和已交付冻结工程保留，运行当前主库不会自动迁移它们。仍须试听最终编码成片；曲目接入不等于节拍、情绪或混音已验收。

## 音量曲线 ENV（dB，余弦过渡）
- 说话密集处：-3 到 -5
- 段落切换前 0.3 秒到切换后 0.5 秒：+4 到 +6
- 画面高潮（作品墙、终结、行动起来）：+5 到 +7
- 情绪低落段整段：-3（按实际曲目和旁白试听）
- 片尾说明卡没有人声：+5，最后 0.8 秒淡出

## 重拍 HITS
- `crash`：切到新画面的最强拍（数量跟随实际高潮，不固定配额）
- `drop`：大字砸下、黑场、震动
- `riser`：转场前 1 秒 → 转场点
- 此类声音主要提供节奏与能量，仍需检查与音乐、旁白的频段和响度是否相互遮盖

## 素材原声 showaudio.wav
其他模型的成片、MV、演示视频的原声。每段先归一化到约 -20 dBFS RMS，再按 0.08–0.16 的增益放到对应时间，前后淡入淡出 0.3/0.4 秒。配乐包络写法可参考 `examples/audio-composition.py`；素材原声的消费区间和混音须由本次工程提供。没有原声素材可以不做，pipeline 会自动补一轨静音。

## 混音（pipeline.sh mix）

`macro-build` 的配置可提供 `mix:{musicVolume:0.42}`。第一次混音读取本期选择，没有记录时以 0.50 起步；也可通过 `pipeline.sh mix 工程 0.42` 显式调整。混音成功后工程保存 `mix_recipe.json`：实际增益、是否有人声、时长、处理图、输入/输出摘要和 FFmpeg 版本。再运行时默认使用已保存的选择；同一时长和设置继续使用保存的处理图，显式调整或修改片长才重新生成。数值示例是起点，仍需实际试听。

新宏工程还固定 `audio_runtime/mix_recipe.py`。既有工程没有记录时沿用当前默认；首次传入以前使用的明确增益即可补记，不能从最终响度反推出原制作参数。最终工程、输入和发布版本一起保留，避免只靠作者的命令历史重现声音。

- 人声：highpass 70Hz → 压缩 2.5:1 → loudnorm -16
- 素材原声：被人声侧链强压（ratio 8，release 350ms）
- 配乐：音量 0.50 左右（用户配乐）；被人声侧链温和压低（ratio 3，release 450ms）
- 音效：0.5，highpass 60Hz
- 总线末段：`alimiter=limit=0.92:level=false`，关闭 limiter 的自动增益，避免把限制后的电平补回 0 dB。
- 合成完成后再做交付级归一化：`loudnorm=I=-15.5:TP=-1.2:LRA=9`，随后 `aresample=48000` 输出 48 kHz PCM。前面的人声归一化只处理人声轨，不能替代完整混音的最终检查。
- 以上是处理目标，不是任意素材的实测保证。每片检查混音和最终编码成片的 integrated loudness、true peak 与时长；交付目标 I 为 -15 到 -16 LUFS、TP 不超过 -0.5 dBTP。
- 混音预留 -1.2 dBTP 的峰值目标，给 AAC 编码后的峰值变化留余量；编码后仍需复测。TP 用 `ebur128=peak=true` 或 loudnorm 的测量结果核对，不能以 sample peak 代替。

## 可调起点（不是每首配乐的固定增益）
| 位置 | 配乐比人声低 |
|---|---|
| 说话时 | 17–20 dB |
| 停顿时 | 12–14 dB |
| 高潮 | 8–10 dB |
| 素材原声 | ~20 dB |
测量时分别抽取说话段和停顿段，比较各轨的 RMS，再听关键字是否清楚。响度和真实峰值以最终混音/编码文件测量为准。
用户说"几乎听不到"：把配乐音量调高 0.2–0.3；说"太吵"：降 0.1–0.15，或者把 ENV 高潮处调低。
