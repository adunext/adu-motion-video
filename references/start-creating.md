# 引导开始创作

用户可直接发送：

```text
加载这个 skill，引导我开始创作。
```

离开仓库上下文时推荐写清名称：

```text
加载 adu-motion-video Skill，引导我开始创作。
```

## 加载后的第一条引导

实际读取本 Skill 后，向尚未提供素材的新用户发送下面这样的简短引导，按已有信息删掉重复问题：

> 已加载 adu-motion-video。把你已有的素材发来，我会先检查内容，帮你选模板、安排动画和字幕，完成后交付 MP4 和可编辑工程。
>
> **先发这些就能开始：**
>
> 1. **你的素材**：口播视频最好；也可以先发文案或旁白音频。直接上传到聊天，或在可访问本机文件的助手中告诉我素材文件/文件夹路径。
> 2. **视频方向**：简单说要讲什么，并告诉我要横屏还是竖屏。不确定时，告诉我准备发到哪个平台，我帮你判断。
>
> **有的话一起发：**字幕 SRT、演示录屏、配图、Logo 和想用的配乐。没有这些，也可以先整理创作方案，我会根据选中的镜头告诉你具体还缺什么。
>
> **模板可以晚一点选**：已有偏好就告诉我编号，例如 01-B 或 06-A；没选好，我会按内容推荐合适的风格，并说明需要哪些素材。
>
> 你可以直接回：“素材在……，想做竖屏，模板帮我推荐。”我们从检查素材开始。

若用户已提供素材/画幅/模板，确认收到并开始检查；不重复索取、不要求一次填完表格，也不只发欢迎语而停下。无法访问附件或本机路径时准确说明，让用户把文件放到当前助手能访问的位置，不能声称已经打开素材。

## 助手如何往下引导

1. **核对已收到的素材**：列出实际可读文件及其用途、真实时长、是否有口播/字幕/证据/配乐。用户只有文案时先整理表达与分镜；只有音频时先讨论无人物图文路线或补真人视频，不能承诺现有真人模板能直接用音频生成真人口型。
2. **只补当前必需的信息**：优先确定横竖屏和视频目的；输出目录、双语字幕、品牌和配乐等到需要时一次简短询问。不强制用户填写 JSON、槽名、精准 cue 或工具参数。
3. **按表达推荐模板**：给2–3个真正适合台词且支持所求画幅的选择，说明风格、适合原因和还需什么。用户已指定模板就沿用其选择，能力缺口说清；不是让用户反复选模板。候选说明待本期声画确认。
4. **整理素材与分镜**：助手生成 brief、真实原文依据和匹配输入；已有 SRT 复用，没有 SRT 可以先写分镜草案，但实际制作前须取得可靠字幕/动作落点。当前环境无法取时就明确缺口，不用源演示秒点代替。缺录屏时换合法无录屏组或请求真实证据，不伪造验证画面。
5. **说明制作方案并推进**：简述模板、画幅、主要镜头、字幕及音效。只询问实质尚未确定的选择，已授权的制作直接进行。竖屏默认字幕整块水平居中、底部18%留白，发布界面和人物避让另检查。修剪默认关闭，不能把“引导我开始创作”当作同意删除口播。
6. **交付与修改**：提供 MP4、可编辑工程、可打开的预览和真实绝对文件路径。告诉用户怎样反馈：“时间点 + 想改的内容”，并简要说明已测范围；不将机器 ready 当作用户已接受效果。

## 一条便于复制的素材消息

```text
素材：/我的素材文件夹（或直接上传文件）
主题：这条视频主要讲……
画幅：竖屏 / 横屏 / 请按发布平台建议
模板：帮我推荐（也可以写已有编号）
补充：字幕、录屏、图片、配乐有的话一起提供
```

这是帮助用户开始的示例，不是必填清单。先收到一个视频和一句方向也应开始核对，后续逐步补齐。不同系统/助手的实际可读路径与执行能力以当前环境为准；具体安装说明见 compatibility.md，不在第一条引导里堆命令和依赖版本。
