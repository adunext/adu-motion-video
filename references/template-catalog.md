## Agent 如何使用编号

04-A 是新 Canvas 仪器台路线，已有双输入融合、三步对话、手册交付三个完整组及适配合同。先读[范围与验收边界](doubao-console-template.md)；技术重放不能代替不同内容验收。首页为 3.9 秒静音局部，不含人物、字幕或原配乐。

1. 用户指定 `01-B` 或“模板 01 的 B 风格”时，映射为 `continuous-performance@1.0.0`；运行 `packs` 确认已安装，再读取该包的 README 和 manifest。编号是用户选择入口，构建命令仍传完整包 ID 与版本。
2. 用户只说“模板 01”时，说明可选风格；没有偏好可先用已发布的 01-A，告知实际选择。用户已指定二级风格时不得静默换风格。
3. 01-C/D/E 已随 3.2.0 各发布三个完整组；运行 packs 核对本机是否已装对应 1.0.0，用户已指定时按该版本制作。首页保留的 demo 是源演出风格短段，不是新内容整片证据；实际新内容与独立使用摘要在包 review.json 及能力矩阵。用户本机只有旧版本时，按所需版本更新，不把其它路线当作指定风格。
4. 按新文案意义选择镜头组，核对必填文字、时间、口播和证据媒体。demo 仅展示效果，不作为用户的新片素材；不能沿用示例的真人、声音、字幕或数据。
5. 需要图标、装饰、象征插图或辅助动画时，可查 [阿杜导演动画素材 API](lottie-assets.md)。API 素材不能代替用户的真人、真实产品界面或操作证据；只有选到符合插槽的媒体后才能接入。仍按所选包完成检查与导出。
6. 用户指定 `03-A` 或「深色 3D」时，读取[模板说明](dark-3d-template.md)，发现并选择 `anim4-showcase-macro@1.1.1-candidate`。按本期实际材料选择完整场景，竖屏运行该版本的布局适配器。说明候选仍待连续声画确认；作品墙、多屏比较与软件录屏的素材要求分别核对。

## 分类维护

同一叙事模板的画面表现差异作为二级风格；新的叙事模板才分配新的一级编号。镜头组、基础 TPL、横竖画幅、字幕大小、演示视频标题都不是一级模板。手绘续接目前是方法与教学示例，在形成可发布模板前不分配正式编号。

增加模板或风格时同步 README、此表、结构化目录与 demo，并写清所需素材和实际发布范围。01-C/D/E 发布后在原编号下更新版本和状态，保留已有编号；不要把旧演出预览描述为新的完整成片验证。

当前已发布包边界见 [能力与验收矩阵](../docs/capability-matrix.md)，制作步骤见 [SKILL.md](../SKILL.md)。

05-A 提炼关键词递进、成果交接和反馈升级三个完整组，包含命名输入、固定数量、独立前态与声音尾音合同。横竖屏从首版同时提供；[详细使用范围](vivid-sticker-template.md)。公开示意预览与原片贴纸有区别，不能作为新片声画验收。
