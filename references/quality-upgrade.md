# 3.13.0-rc.2 质量升级候选

本次以 3.12.0 为基线，最终保留升级由所有者完整看听同输入 A/B 后决定。代码通过、静帧和短片回放不等于艺术效果已接受。历史稳定十七组保持原版本验收，新增组仍为 candidate。

## 制作顺序

1. 阅读完整口播，保留原文、原 SRT 和原素材；记录版本、画幅、字体、素材 offset、曲目与声音设置。
2. 默认 `repairPolicy.mode=off`。只有本轮用户明确开启 basic 才制备一个修剪母版，并在新时钟上重新分段；不继承旧工程的修剪许可。
3. 根据真实表达、数量和媒体选择完整组。横屏/竖屏分别读取目录 `selection`/`portraitSelection`。当前横屏 10 风格/47 组，竖屏 11 风格/54 组；画幅不支持不是缺素材。
4. 将原文身份及句级 `ownershipRefs` 接入 brief/spec，全部保留口播按序归属一次；显示文字 `supportingRefs` 可重复引用。助手核对否定、条件、数量、单位、实体与比较方向。无可靠词时码不编造词级锚点；跨分段句无法可靠归属时报告 source-unrecorded。
5. `macro-plan` 或 `auto-plan` → 检查报告 → build；新增素材走 rematch，共用完整媒体、接缝和根时间线声尾校验。保存的 auto-plan 冻结 `catalogBindings`，新增无关包不自动换组。
6. 用实际字体、viewport/DPR 和 transform 测量文字；检查人物、标题、字幕与平台覆盖。超容量调整布局/短标题或换组，不无限缩字。导出后检查最终编码并连续看听完整影片。

## 字幕与声音

字幕默认保留整句及合理重叠，半开区间 `[t0,t1)`；缺可靠词时码不逐字假高亮。竖屏整块底边位于画面高度 82%，左右各 15%留白，多行向上展开；可用 `subtitlePosition` 比例覆盖。该设置是项目设计起点，需要按实际人物、标题和目标平台检查。横屏沿用位置预设。普通文字安全显示，SRT 明确标记 srt-basic 才解析 b/i/u，其他标签和属性作为原文。

SFX 事件身份/种子与混响 IR 固定并与 BGM 随机流隔离；纸面/杂志家族使用自己的低通配方，其他家族保留音色。报告记录真实干湿缓冲、起音、峰值与支持长度，不能代替人声掩蔽和听感验收。素材视频 offset/速率与编舞时钟分开；只有输出字段重定位，根时间线可承接子组真实尾音。配乐仍显式选择本期 track/path/offset，没有新增自动选曲。

## 可选口播修剪

`repair-plan`/`repair-apply` 的默认 mode 都是 off，关闭时不读取源片、旧 map 或候选。显式 basic 只接受经确认空白窗口，再核对全部图像、逐声道数字静音、字幕、锚点与 PTS。低音量、静态画面、黑色背景和 ASR 空隙不构成删除依据。无法可靠判断时保留原内容。

母版为 60fps/48kHz，每帧 800 PCM 样本；保存源身份、保留区间、精确编辑映射、原/派生 SRT。跨删除区字幕或保护锚点会阻止删除。先 `repair-apply` 制备母版，再把 brief 置为 `narrationClock=edited-narration`、精确新时长及 `repairPolicy.mode=basic`，用 `macro-plan`/`auto-plan --edit-map` 重规划。段落 cue 可引用 `{intakeId:保护点ID}`，只转换源口播点一次；素材源 offset 不动。candidateInterpretations 内锚点仍需提供本期段内时码。母版只处理一次，混合子工程从母版切片，禁止重新切除。

该首版只处理明确单视频与单 mono/stereo 音轨、支持的 PTS、十分钟以内输入；不支持的源需人工整理再规划，不保证自动处理任意 VFR、AAC priming 或复杂音视频偏移。原片/SRT 只读；拒绝覆盖已有目标口播媒体。

## 旧工程与回退

旧冻结工程不会自动改写。旧 auto-plan 优先沿用保存版本；没有 catalogBindings 的旧计划只尝试按已有源摘要恢复版本，恢复失败需另存重规划，不能重写源摘要。修改包版本、输入、时钟或剧情后重新 plan/build；旧人工 spec 不获得新的来源真实性声明。

新导出采用软件绘制与 sRGB，在同路径进行往返 seek 和像素检查；这会影响速度，并可能与旧 GPU 编码有像素差异。恢复基线使用 tag `quality-upgrade-baseline-3.12.0-20261004` 和原输入/依赖；用户未接受前不自动切换其他安装。
