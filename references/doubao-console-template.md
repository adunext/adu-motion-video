# 04 · 深色科技控制台

**04-A · 仪器台演示** → `doubao-console-performance@0.1.2-candidate`。

从豆包工程提炼的独立路线：Canvas 粒子与仪器刻度、玻璃面板、轨迹汇聚、对话步骤和文件交付。当前是三个完整镜头组的候选，不代表原工程全部二十场已模板化。

| 完整组 | 表达用途 | 原速时长 |
| --- | --- | --- |
| fusion-success | 两个输入合并，落到明确结果 | 3.9 秒 |
| three-step-chat | 三步说明与对话演示 | 9.0667 秒 |
| manual-agents-delivery | 手册、多个执行者与交付物 | 11.4667 秒 |

每组已有语义阶段、内容容量、动作锚点和运动家族合同，可进入 `macro-plan`。保护完整动作窗，不支持任意按句切碎或变速挤入更短口播。三个组的不同效果可用于同一视频；相邻衔接和音效尾音仍需对照本期实际时间线。

输入为本期剪好的口播、文案、图片、明确提供的 `grainTexture` 和固定 SHA 的 Geist / GeistMono 字体。用包内 README 与 manifest 的字段约束填配置。新语音光晕从本期 `voice.wav` 重算，人物与进度使用输出时钟，动画仍用源编舞时钟。源 BGM 不分发，默认合成音乐是新配乐。

0.1.2 修复新文案实际暴露的三类问题：手册名称裁切、长标题被手册卡遮挡，以及状态卡/步骤标签侵入相邻区域。按真实字形宽度有界调整字号和换行，保留可读下限；达到下限仍放不下时明确拒绝，不能裁掉正文。完整动作时钟、锚点、原音效与素材槽保持不变。

本次检查使用短、中、近上限中文与中英混排四套新内容，共 792 个抽样帧、208 个文字槽，实际加载并核对 8 个外置字体的 SHA；未发现裁切或资源错误，固定区域与反向寻帧检查通过。画面明确标注静音排版检查、无人物；这些结果只覆盖展示文字，仍需用新的真实口播验证完整声画与独立复用。另有最大 CJK/Latin 字宽、字号下限和异常输入拒绝的浏览器回归。

原 0.1.1 已做同内容技术重放：三组共 1466 帧（24.4333 秒），对照三个源关键帧、真实字体和布局；34 条动作音效的类型、参数和映射时间逐项一致。为了检查完整尾音，私人 QA MP4 另加明确标示的 2 秒黑场，共 1586 帧（26.4333 秒）；这不是模板第四组，不可用冻结人物补尾。成片已全解码、逐帧时钟与 BT.709 标签检查。

浏览器检查覆盖 142 个抽样帧、37 个时间映射节点和 5 次重新加载比较，结果 **0 issue / 4 warning，needs-raster-review**。保留严格栅格差异，不降低阈值。该控制重放使用原内容、原人物跟踪映射和 QA 专用放宽的文案限制，只证明提炼一致性；同内容记录不包含不同文案；0.1.2 的新文案静音检查另见上文，尚未完成新的口播连续声画与独立作者复用验收。当前仅横屏 1920×1080 / 60fps，未宣称原生竖屏。
