# 03 · 深色 3D

**03-A · 多屏展陈**：以深色舞台、立体卡片与窗口、镜头推进、作品墙和重点放大组织口播。适合产品演示、工具评测、作品集、成果发布与工作流比较。视觉分类固定为「深色 3D」，视频话题与产品名称由本期内容填写。

调用版本：`anim4-showcase-macro@1.0.0`。本模板复用已有 `packs/anim4` 的九场完整编舞与素材准备器，不新增一套同名运行代码。当前为 **experimental / 试用**，不计入十七个稳定镜头组；编号接入不改变包的验收状态。

## 视觉与动作

- 深灰黑舞台、低对比网格、蓝色重点与发光描边；前后层次由窗口阴影、景别变化、卡片缩放和镜头运动组织。
- 主讲人可从大卡片缩成圆形人物窗；多屏材料按次序出现，分组高亮，再交给重点作品。
- 重点放大后继续进入结论、报告或真实操作。保留准备、主动作、结果与离场，避免把完整镜头压成静态截图。
- 源编舞含白色和蓝色段落，用于节奏转折。需要以深色为主时，优先按意义选择 `s02 / s03 / s05 / s08 / s09`；保留选中场景的完整动作与素材要求。
- 横屏原规格为 **1920×1080、60fps**。运行方式沿用 HTML/CSS/JavaScript；竖屏须为各场另做布局与验证。

## 九场可复用编舞

下表时码是参考编舞时间，制作新片时由本期口播确定目标时码。每场可独立选择、重排或重复；镜头交接仍须按实际相邻关系检查。

| 场景 | 源区间 / 原长 | 完整演出 | 本期必须准备 |
| --- | --- | --- | --- |
| `s01` 开场与展陈 | 0–8.80 秒 / 528 帧 | 双行标题 → 剪辑时间线 → 划除与盖章 → 人物缩窗 → 作品墙 → 结论 | 开场主张、痛点与结论；至少 27 个独立作品及其清单 |
| `s02` 多屏比较 | 8.80–25.90 秒 / 1,026 帧 | 九屏错峰入场 → 分组高亮 → 型号或版本切换 → 全选确认 → 指标滚动 | 9 路真实比较视频、名称、分组、指标与数据依据 |
| `s03` 重点与报告 | 25.90–40.40 秒 / 870 帧 | 九宫格中心作品放大 → 结论砸字 → 对比板 → 扫描与三项报告 → 前作卡 | 重点成果视频、前作视频、三项观察与有依据的时间/数值 |
| `s04` 品类与镜头 | 40.40–52.70 秒 / 738 帧 | 四品类卡 → 大作品墙 → 划除旧模式 → 景别演示与叙事弧线 | 4 类作品视频、作品清单、来源图标、镜头示例 |
| `s05` 身份与软件 | 52.70–69.40 秒 / 1,002 帧 | 情绪冲击 → 身份卡 → 真实软件窗口 → 竞赛道与成果交接 | 产品标识、软件操作录屏、成果视频与本期主张 |
| `s06` 迭代与账号 | 69.40–78.10 秒 / 522 帧 | 迭代时间线 → 多方入场 → 快车道 → 账号卡 | 授权头像、名称、真实数据、迭代与行动文案 |
| `s07` 工作流变化 | 78.10–89.70 秒 / 696 帧 | 旧工作流 → 时间压缩 → 工作窗口 → 代码窗口 | 工作与代码录屏、前后耗时及其依据 |
| `s08` 产能与行动 | 89.70–102.92 秒 / 793 帧 | 情绪收束 → 产能对比 → 逐帧焦虑 → 行动号召 → 留言收尾 | 授权头像、本期产能数据、结论与具体行动 |
| `s09` 制作片尾 | 102.92–108.40 秒 / 329 帧 | 制作说明 → 逐字提示词 → 签名 | 实际制作工具、真实提示词、署名与授权头像 |

合计 108.40 秒、6,504 帧。`s02 / s03` 含持续播放的比较与重点视频，整场保持 1×；其他场景按保护动作窗运行，只有允许停留的间隙可延长。

## 可替换内容与素材

当前接口包含 **222 个槽位、66 个语义动作节点、42 个动作保护窗**。其中 26 个节点需绑定本期台词落点。先生成配置再填所选场景，具体槽位、字符容量、媒体帧数与动态数值约束以 [manifest](../packs/anim4/manifest.json) 为准。

需要剪好且长度确定的真人口播、对应文案、时间码字幕、账号名称，以及所选场景的真实录屏、作品视频、图像和配乐。九屏比较需要 9 路独立视频；作品墙至少 27 个独立作品，循环铺满的格子数不能当作独立作品数。媒体准备方法见[完整包说明](../packs/anim4/README.md#媒体准备)。

画面字、数字、版本、时间、报告结论、头像、标识、作品与录屏均用本期输入。长解释交给字幕，短标题承载重点。源演出观看预览不作为新片输入分发。

## 直接使用

```text
使用 adu-motion-video 的 03-A「深色 3D · 多屏展陈」，
按我的口播与实际材料选择完整场景，保留窗口纵深、镜头推进和原动作节奏。
口播、字幕、作品与录屏在：/我的素材目录
输出 MP4 和可编辑工程到：/我的输出目录
这是试用模板，请检查所有转场、文字、口型与声音后交付。
```

```bash
bash scripts/pipeline.sh packs
bash scripts/pipeline.sh macro-spec anim4-showcase-macro@1.0.0 /已有目录/本期配置.json
# 删除未使用的场景，填写本期 slots、cues 和素材；所选场景总帧数应等于剪好口播
bash scripts/pipeline.sh macro-build anim4-showcase-macro@1.0.0 /已有目录/本期配置.json /已有目录/剪好口播.mp4 /已有目录/新工程 --subs-js /已有目录/本期字幕.js
```

新配置和工程路径必须事先不存在。使用新工程的目标时钟读取人物与字幕，以映射后的源时钟运行动作；源配乐结构与 175 个音效事件按新时间线重新编排。完整制作和验收步骤见[完整工程复用](full-project-templating.md)。
