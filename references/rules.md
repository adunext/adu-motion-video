# 用户偏好与禁区（阿杜Next）

以下由历史制作整理，作为后续口播成片的默认偏好。当前用户明确要求优先，例如本次只出竖屏、制作静音样片或缩短片尾时，按本次任务执行；不因历史流程重复请求批准。

## 身份
- 账号名：**阿杜Next**（N 大写）。右上角角标：**AduNext**
- 简介：使用本次创作者提供的公开介绍。
- 真人头像：由本次用户提供；公开包不含人物照片。
- 产品 logo：由本次用户提供并确认使用范围；公开包不含品牌图片。
- 片尾自称可以用"Vibe coder 阿杜"或"阿杜Next"

## 规格
- **16:9，1920×1080，60fps**。竖屏另出一版，不替代横屏
- 整片响度约 -15 到 -16 LUFS，峰值 ≤ -0.5 dB
- 改版另存 `_v2/_v3…`，不要覆盖旧版

## 画面
- **真人口播是主线**，放在圆角 "// on air · 阿杜" 卡片里，按内容变换位置和形状（右侧大卡、右上角小圆圈）
- **第一帧就要有口播画面**
- 小圆圈里**脸要在正中间**（用 face.js）
- 开场第一句是**大标题**，快速放大砸入，配闪屏和震动；**不要逐字淡入**
- 卡通人物只做点缀；**不要纠结手部骨骼动画**（EP02 v2 被否）
- 底色只在白（#F7F7F5）、黑（#0A0A0A）、蓝（#2462EA）三者之间整屏切换
- **苹果风字体**：苹方、Geist、SF Mono。**禁用书法、行楷、毛笔字体**（EP01 被否，评价"太难看了"）
- 强调词用中文，不要中英混排（比如"薄肌 *lean.*"这种）
- **禁用荧光绿**
- 用户提供素材（软件录屏、其他模型成片、MV）时，指定用哪一段（"14～17 秒"）就严格用那段，可以加速但要标出倍速（▶▶ 2.4×）
- 网络收集的作品要标注"网络优秀作品收集 · 非个人原创"，**不要露出 GitHub 网址**

## 字幕
- 中英双语，底部，逐字变色跟随口播（念过的字变白，正在念的字变蓝，没念到的是浅灰）
- **白字 + 深色描边**，不加底板，不加光晕（灰色底板和黑色光晕都被否过）
- 中文去掉语气词、修正识别错字，但保留原意；用户点名的措辞照改（比如在"今年年初"前加"从"）

## 声音
- 用户提供了配乐就**优先用**，要踩准节拍点
- 配乐要**听得出来**、**跟着节奏起伏**，但不能整体都很大：
  - 说话时比人声低约 17–20 dB，停顿时约 13 dB，高潮处约 8–10 dB
  - 比人声低 20 dB 以上时，用户会说"几乎听不到"
- 素材原声（其他模型的成片等）要**明显压在人声下面**，约低 20 dB
- 每个出现的元素都配适当音效；已有合成音效库可复用，外部声音素材按实际来源处理。
- B-roll（插入纯音乐停顿）目前**不做**，除非用户主动要求

## 片尾
- 口播结束后默认接约 5.5 秒的“制作说明”卡：填写真实制作模型/工具、实际使用的 skill 和简短核心提示词。改编旧片时区分原版制作与本次修改；不要沿用旧片的“无 skill”或固定时间。

## 交付时怎么说
- 路径 + 规格 + 逐条对应用户的修改意见
- 按实际说明检查范围，例如“已抽帧检查，未从头到尾播放”；如果完成了完整播放或解码检查，分别准确说明。
- 示意数据（评分、token 数、点赞数、×10 这类）要标注"示意，不是实测"
- 未核实的事实单独列出
- 口播里的数字（比如"30 分钟"）和画面上的数字要一致；不一致先问用户
