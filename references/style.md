# 现代图文动效：默认视觉起点

这套值对应 1920×1080 DOM/SVG 模板，可按用户品牌调整；手绘卡通另见 [handdrawn-animation.md](handdrawn-animation.md)。相同片内保持层级和用色一致，竖屏必须重新排版。

## 配色
| 名称 | 值 | 用途 |
|---|---|---|
| paper | `#F7F7F5` / `var(--paper)` | 白底 |
| ink | `#0A0A0A` | 黑底、正文 |
| blue | `#2462EA` / `var(--blue)`；深色底上用 `#6d9bff` | 默认强调色 |
| g1 | `#8C8C8C` | 标签、次要文字 |
| line | `#E7E7E4` | 网格、描边 |
| 红（只用于否定） | `#E5484D` | 划掉、STOP、警告 |
| 绿（只用于开关、PASS） | `#28c840` | 开关、打勾 |

## 字体
- 标题：`-apple-system,'PingFang SC'` 600–800，字距 -1 到 -6px
- 等宽标签：`'SFM'`（原片优先 SF Mono）或 Geist Mono；缺失时使用随包 Noto Sans Mono，22px，灰色，格式 `// 02 — 实测`
- 大标题 150–190px，h1 108px，h2 88px，h3 56px（style.css 里的 .h1/.h2/.h3）

## 版式
- 左边距 146px；右上角是小圆圈口播（中心 1745,180，250px，缩放 .75）
- 右侧大口播卡片：470×836，中心 (1520–1570, 505–510)，缩放 .9
- 字幕区：y 870–1040，其他大元素不要进入这个区域
- 底部赛道进度线：y 1058
- 左上角是段落标签 `// NN — 名称`，右上角可放用户品牌与 `00:00:SS:FF` 时间码（tags() 自动生成）

## 动效节奏
- 可以每 2–4 秒安排新的视觉事件，但以语义和阅读需求为准；关键词出现在口播说到它的**那一刻**（用 SRT 时间码）
- 入场：`show(e,t,t0,{k:'up'|'left'|'right'|'pop'|'slam'|'zoom'|'blur'|'mask'})`，默认 0.55 秒 expo 缓动
- 逐词：`words()` + `wordsAt()`，强调词用 `k:'slam'` 加蓝色
- 转场：`trans:'wipe'|'circle'|'flash'|'blur'`；`circle` 可以指定 `cx/cy`，从某个元素（比如小圆圈）展开
- 数字：`counter(t,t0,t1,from,to)` 配 `S(t,'counter',…)`
- 冲击：`sc.cam = t => ({…shake(t,t0,.35,12)})` 配 `S(t,'hit',1)`
- 背景可以用"作品墙"或素材序列帧，上面叠渐变压暗（左侧 .92 → 右侧 .15、底部 .96），保证文字可读
