# vivid-sticker-performance@0.1.0-candidate · 鲜色角色叙事

三组保留完整动作与源 SFX：关键词光环递进 → 金色结论；两位准备者 → 笔记本交接 → 三位接收者 → 盖章；三条反馈 → 汇入容器 → 版本升级。

横屏1920×1080与原生竖屏1080×1920，均60fps。语义规划优先macro-plan；手动macro-spec只生成待绑定草稿。修改inputs和本期真实cue，不要沿用原视频的时码。动作窗整体保护，短于原完整演出时长拒绝；不能从交接半途开始或单独切出印章。

文案、章节、工具名、版本和标签均有名槽；交接组固定两位准备者/三位接收者，反馈组固定三条，光环固定六个关键词。数量不符须换组或另提炼变体，不静默丢弃。图像只消费明确的giver/transfer/receiver三槽；提供获授权的透明PNG，姿势与物件交接方向匹配。

必须使用本期口播、人脸裁切、grainTexture与固定SHA的Geist/GeistMono字体。媒体/字体不随公共包分发。macro-build会复制媒体、冻结代码与语义/媒体时钟；新内容的源品牌和图像不能留下。

默认配乐是明确替换的重合成底乐；原商业录音不包含、不宣称复现。源ENV/HITS与动作SFX随组映射；视觉beatK保留源演出脉冲，使用新曲须核验节拍与冲击。保留尾音并审核两侧接缝。

字体按实际字宽有界收敛；超过可读下限会拒绝，不省略内容。最终字幕还须检查长句与安全区。所有版本仍是候选：几何、绑定和静音源码对照不能代替新真人口播、连续声画和独立使用验收。原25段只选择上述3组；未宣称整片模板化。
