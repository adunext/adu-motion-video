# 阿杜动画模板提炼

将用户指定的完成工程提炼成可追溯、可绑定新内容的完整镜头组。模板名称、来源和画幅以用户要求为准；原片标题不自动成为模板名。

先定位本次实际使用的 **adu-motion-video 仓库/安装目录**，记录其版本、执行入口与输出路径。仓库内本 Skill 位于 `skills/adu-template-extractor`，主库为上两级目录；独立安装时查找同环境已安装的 adu-motion-video，或使用用户指定仓库。需要它的提炼器、规划器和构建器；缺少时先完成源码清点与合同草案，说明缺少的具体工具，不把草案当成已接入模板。

读取主库 `references/rules.md`、`references/template-intake.md`，再读本 Skill 的[提炼与验证流程](references/extraction-workflow.md)。根据源引擎选择已有 adapter 或编写锁定来源的新 adapter，不要求所有来源改成同一种代码结构。

核心约束：

- 来源和成片保持只读，冻结修订、源区间与实际 helper；旧公开版本保持原字节。
- 公共模板彻底清除个人姓名、账号、链接、头像、路径和本期数据，品牌/人物标签由新输入绑定；追溯只用匿名修订/摘要，保留必要许可证。扫描 config、helpers、HUD、示例、默认值和预览，不能只清 manifest。
- 每次提炼同时补充适合该风格的基础动画（关键词、要点、解释、结论等），按真实需要选择；为每组定义容量、合法延长、独立进出和音效，标记源动作与新创扩展，不能假称新动画来自源片。
- 提炼完整因果演出，不以句子、空白或 AST 大括号直接决定声画剪点。独立初始化、前后依赖、动作窗和尾音一起进入合同。
- 字幕、人物与视频用新输出时钟，编舞用源时钟；不能慢放口型、循环证据或冻结真人来补时长。
- 首版同时设计本次需要的画幅、输入容量、数量、真实动作锚点与合法邻接。只实现竖屏就明确只有竖屏，规划器不能把它选进横屏影片。
- HDR/DV 先探测再走主库色彩流程；不能用滤镜掩盖转换错误。原头像、录屏、第三方作品、录音与字体许可分别处理。
- 记录实际检查范围：源码对照、静音换稿、真实构建、最终编码、连续听看与独立使用互不代替。未验收的候选可发布准确范围，不自动标 stable。

交付包括新候选包、可操作的输入说明、适配 profile、目录与预览、来源/验证记录。用户已授权 GitHub 更新时提交公开源码和合规预览；私人媒体、日志与原成片留在私人输出目录。升级结束简要报告产品名、版本、主要新增/修复与验证限制。

Windows、macOS、Linux，以及 Codex、Claude Code、豆包、DeepSeek、WorkBuddy 均可使用此流程，前提是当前助手能读写文件并运行工具。Bash 命令在 Windows 通过 WSL；实测平台单独注明，字体和媒体路径用当前环境的实际值。
